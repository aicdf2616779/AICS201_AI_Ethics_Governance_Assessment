# AICS-201: AI Ethics, Governance and Legal Compliance

## Project Overview

This project evaluates the ethical, governance, legal and
algorithmic fairness risks associated with SecureFinance Africa,
a fictional AI-powered financial technology platform.

## Assessment Objectives

1. Identify ethical risks associated with AI deployment.
2. Apply the NIST AI Risk Management Framework.
3. Evaluate applicable legal and regulatory requirements.
4. Conduct algorithmic fairness and explainability testing.
5. Develop a professional AI governance assessment report.

## Technical Environment

- Operating System: Kali Linux
- Programming Language: Python
- Version Control: Git
- Repository Hosting: GitHub
- Dataset: Synthetic data only

## Project Structure

- data/: Synthetic datasets
